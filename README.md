
# SDL_gpu_examples for Dart
Contains code samples for all chapters of SDL_gpu_examples and [https://github.com/TheSpydog/SDL_gpu_examples](https://github.com/TheSpydog/SDL_gpu_examples). 

This source has been translated by [Dart](https://dart.dev/).

# Windows (64bit) building

## 1.Install

### Dart for Windows

[http://www.gekorm.com/dart-windows/](http://www.gekorm.com/dart-windows/)

### Git for Windows

[https://gitforwindows.org/](https://gitforwindows.org/)

### Visual Studio Code for Windows

[https://code.visualstudio.com/download/](https://code.visualstudio.com/download/)

## 2.Git clone

Type the following command in the shell.
```
git clone https://github.com/sansuido/sdl3_gpu_examples
```
or

Download ZIP, and unzip.

## 2.Change Directory & Pub get

```
cd sdl3_gpu_examples
pub get
```

## 3.Execute

```
dart ./bin/main.dart
```

or

Open the directory with VS Code, and run F5 in the source.
